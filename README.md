##  01. Raigam.lk Corporate Website Redesign

An empirical usability evaluation of the live corporate platform (`raigam.lk`), followed by a systematic redesign addressing critical navigational and information architecture failures.

###  Problem Statement & Evaluation
Through comprehensive source code analysis, WCAG audits, and Nielsen’s Usability Heuristics, **44 usability issues** were identified and severity-ranked on the live website:
* **Inconsistent Navigation:** Divergent menus (homepage icon buttons vs. contradictory inner page bars).
* **Broken Catalog Architecture:** 100+ product links routed to dead pages, with zero search, filter, or pagination mechanisms.
* **No Mobile Optimization:** Complete lack of responsive layout scaling for smaller viewports.
* **Error Prevention Gaps:** Missing form validations, broken routes, and ambiguous system states.

###  HCI Principles & Implementations
* **Consistency & Standards:** Unified global navigation bar implemented across all desktop and mobile views.
* **Flexibility & Efficiency:** Integrated real-time live search, multi-category filtering, and structured catalog pagination.
* **Visibility of System Status:** Breadcrumbs, interactive hero carousels, and clear visual state feedback.
* **Error Prevention:** Robust form validation, active page routing, and dedicated product detail views with a "Where to Buy" locator.

##  02. LankaGO – Inclusive Public Transport App

A unified transit platform bringing SLTB buses, trains, three-wheelers, and ride-hailing into one single accessible interface, engineered for commuters with diverse physical and cognitive needs.

*  **Figma Design File:** [View Design System & UI Space] https://www.figma.com/design/SkLIOb9C31VZz2idEQByYp/LankaGO?node-id=0-1&t=KMSO42eQeWd2US8s-1

###  User Research & Inclusive Personas
The system was architected around 5 core user personas addressing real-world exclusion barriers:
* **Visually Impaired (Nadeeshan):** Screen reader optimization, text-to-speech cues, and zero dependence on color coding.
* **Wheelchair Users (Dilani):** Step-free route filters, station ramp indicators, and advance boarding assistance.
* **Deaf / Hard of Hearing (Ruwanthi):** Real-time visual alerts and non-auditory notification channels.
* **Elderly & Temporarily Injured:** High-contrast large tap targets (minimum 44x44px) and simplified one-tap workflows.

###  Accessibility Principles (The POUR Framework)
* **Perceivable:** High visual contrast ratios and structured screen reader accessibility labels.
* **Operable:** Voice search navigation, generous touch targets, and single-toggle accessibility modes.
* **Understandable:** Trilingual support (**Sinhala, Tamil, English**) configured directly from screen one; short task flows.
* **Robust:** Cross-platform layout stability optimized for entry-level devices.

###  Key Features
* **Accessibility Hub:** Verified accessible route indicators and ramp-equipped vehicle filters.
* **Boarding Assistance:** Pre-scheduled transit support requests for physical accessibility.
* **Delegated / Family Booking:** Remote ride booking and tracking for dependents and caretakers.
* **Emergency Hub:** Rapid-access SOS and visual emergency broadcast interface.
